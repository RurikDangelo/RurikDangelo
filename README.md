## Sobre mim

Formado em Ciência da Computação, desenvolvedor de SaaS e especialista em **IA, LLM e Machine Learning**.
Trabalho do banco de dados à interface, em **C# .NET** e no ecossistema **TypeScript**, construindo sistemas que empresas reais usam o dia inteiro.

- Hoje desenvolvo o **NIT**, uma plataforma multi-tenant de ERP e CRM conversacional no WhatsApp
- Fundei a **Tivexy**: sistemas sob medida, automação e inteligência artificial para empresas
- Construo agentes de IA com ferramentas reais (Claude API, Agent SDK, MCP, RAG)
- Gosto de medir antes de otimizar: uma policy de RLS reescrita saiu de 149 ms para 6,9 ms
